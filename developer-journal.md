## 26. 10. 2026 — fork `jev-extension-fork`

### Project State
- Fork of the 1.0.0 tree, kept as a separate folder + own git repo (branch `main`).
- Original folders `jev-extension` and `jev-extension-v2.0.0-dev` are untouched.
- `developer-journal.md`, `README_FIXED.txt` and `README_FORK_STRUCTURE.md` were
  restored after being deleted by mistake. From now on this journal is only
  appended to, never rewritten.

### Changes
- **Persistence across navigation.** `manifest.json` now declares
  `content_scripts` (Bazos domains, `run_at: document_idle`), so the script runs
  on every page load instead of only after clicking the toolbar icon. Stored
  criteria are re-applied automatically.
- **Stable storage.** Added `browser_specific_settings.gecko.id`
  (`jev-content-filter@local`) so `storage.local` (API key, criteria, mode,
  on/off) survives rebuilds and reloads.
- **Duplicate-instance guard.** `globalThis.__jevFilterLoaded` — a second
  injection only re-opens the panel; no second observer / interval.
- **Mode buttons fixed.** The single toggle button labelled the current state
  instead of the action, so "hide" and "dim" looked swapped. Replaced with two
  explicit buttons (Skrýt / Ztlumit) and an `.active` highlight on the current one.
- **Green highlight restored.** Ads the model evaluated and kept get
  `.jev-green` (`#E8F5E8`) as visual confirmation that filtering ran. Hidden ads
  never keep the tint.
- **Cost / loop protection.** Requests are batched (10 ads per call), decisions
  are cached per criteria+text, and ads that errored are marked
  `data-jev-state="error"` so the observer can never retry them forever
  (the leak that burned ~86M tokens).
- **Clear keeps the API key.** Clearing the filter no longer wipes the key.
- **i18n tooling.** `locales/*.json` is the source of truth; `_locales/<lang>/`
  is generated by `scripts/i18n-build.mjs`. Added `i18n-check` (missing/extra/
  empty keys) and `i18n-add` (scaffold a new language). Default locale: `cs`.
- Removed dead code from the fork: root `background.js` (JevClient),
  `popup.html` / `popup.js` (never referenced by the manifest).

### Open questions

  I want it, off when I don't" — a per-domain opt-in model may be preferable.
  Not changed yet, waiting for a decision.
